# Phase 0 Roadmap

Phase 0 turns the seed research notes into a ready repository and a buildable first sprint.

## Initialization

- Create repository scaffold, verification targets, CI, and GitHub remote.
- Deduplicate research notes.
- Add evidence, lens, and research-state vocabulary schemas.
- Add homelab-analytics registry manifest and no-op integration hooks.

## First implementation sprint

Recommended sprint name: `finland-evidence-spine`.

Deliverables:

- Finland-first source inventory.
- Evidence model spec with source confidence and comparability fields.
- Lens model spec with dimensional scorecard and allowed research-state transitions.
- Homelab-analytics publication-contract spike.
- Success criteria for six-month decision impact review.

Initial specification artifacts:

- `docs/specifications/finland-source-inventory.md`
- `docs/specifications/evidence-record-spec.md`
- `docs/specifications/lens-scorecard-spec.md`
- `docs/specifications/decision-output-contract.md`
- `docs/specifications/hla-publication-contract-spike.md`
- `docs/product/six-month-success-criteria.md`

## Later phases

- Phase 1: ingestion and normalization for governance, remuneration, ESEF, PDMR, earnings-call, and event evidence.
- Phase 2: longitudinal feature extraction and same-firm-over-time views.
- Phase 3: dimensional scorecards, lens outputs, and research-state transitions.
- Phase 4: curated publication and HLA integration.
