---
name: pr-handoff-summary
description: Use when preparing a final implementation handoff or reviewer-facing summary.
---

## Goal

Summarize what changed, what was verified, and what still needs attention.

## Steps

1. Summarize the outcome, not a file inventory.
2. Name the highest-signal files or contracts.
3. Include exact verification commands already run.
4. State residual risk or follow-up.

## Do not

- Do not omit verification status.
- Do not substitute this summary for a findings-first review when review was requested.
